# تحليل — Tahlel

MVP لتحليل مواقع ومتاجر إلكترونية.

## الوظائف
- الزحف إلى الصفحة الرئيسية والصفحات الداخلية.
- إعطاء أولوية للاسترجاع والاستبدال والشحن والخصوصية والشكاوى والتواصل.
- تحليل AI عند توفير `OPENAI_API_KEY`.
- توليد تقرير PDF.

## التشغيل
```bash
pip install -r requirements.txt
export OPENAI_API_KEY="your-key"
streamlit run app.py
```

## الملفات
- `app.py` واجهة الاستخدام
- `crawler.py` محرك الزحف
- `analyzer.py` تحليل AI
- `report.py` تقرير PDF

## قبل الاستخدام التجاري
يفضل إضافة تقييمات رقمية وأدلة مصدرية، قالب PDF احترافي، حفظ التقارير والعملاء، دعم سلة وزد، تحسين RTL والخط العربي في PDF، وضوابط زحف وحماية للإنتاج.
